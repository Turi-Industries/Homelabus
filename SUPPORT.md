# Getting help

Homelabus is maintained by one person, in their own time ([GOVERNANCE.md](GOVERNANCE.md)).
There is no paid support and no response time — but a question asked in the right place
is usually answered.

- **A question, an idea, "is this possible?"** —
  [Discussions](https://github.com/Turi-Industries/Homelabus/discussions). Say what you
  ran, what came back, and the output of `hlb --version`.
- **Something reports one thing and does another** — a
  [bug report](https://github.com/Turi-Industries/Homelabus/issues/new/choose). That is
  the bug class this project cares most about: a backup said to exist, a door said to
  be closed.
- **A vulnerability** — never in public: [SECURITY.md](SECURITY.md).
- **Anything else** — contact@turi-industries.eu.

Before asking, [docs/cli-tour.md](docs/cli-tour.md) runs every `hlb` verb with an
example, and `hlb <verb> --help` says what each flag does. Most commands preview by
default: running one without `--apply` is a safe way to see what it would do.
